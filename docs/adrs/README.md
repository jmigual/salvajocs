# ADR index

One short record per design decision: Context, Decision, Alternatives considered, Consequences
(Nygard format). **Read this table, not every ADR.** Open only the rows whose "Read when"
matches your task. Adding or changing an ADR updates its row here in the same commit.

Status is `Accepted`, `Proposed`, or `Superseded by ADR-NNNN`.
